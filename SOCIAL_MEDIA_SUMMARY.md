## 🚀 How to Use Social Media Templates

### Step 1: Access Templates
All templates are located in: `public/social-media-designs/`

### Step 2: Open in Browser
```bash
# Open any template in your browser
# For example: file:///C:/Users/Benjamin/Wilson/public/social-media-designs/instagram-branding.html
```

### Step 3: Customize
- Edit HTML text directly in browser dev tools
- Modify CSS colors and gradients
- Update messaging for your brand

### Step 4: Export
**Option A - Screenshot:**
1. Open template in Chrome
2. Right-click → Inspect
3. Toggle device toolbar to exact dimensions
4. Take screenshot
5. Crop to 1080×1080 or 1200×627

**Option B - Browser Export:**
1. Open template in Chrome
2. Press Ctrl+P to print
3. Select "Save as PDF"
4. Rename to .png or use online converter

**Option C - Figma/Canva:**
1. Copy HTML code
2. Paste into Figma
3. Export as PNG with proper dimensions
