## 🚀 How to Use

### **Quick Start:**
1. Open any template file in a web browser
2. Customize text, colors, or add your branding
3. Take a screenshot or use browser "Export as PDF" → "Save as Image"
4. Upload directly to Instagram, LinkedIn, etc.

### **Pro Tips:**
- Use Chrome DevTools to adjust colors before exporting
- All templates are fully responsive
- Edit HTML source to customize messaging
- Convert to PNG/JPG with tools like:
  - Figma (copy paste the HTML → export)
  - Screenshot tools (Snagit, Greenshot)
  - Browser extensions (Awesome Screenshot)

## 🎯 Performance Tips

**What Makes Social Posts Perform:**
- **Text:** Short, punchy headlines + clear value proposition
- **Visuals:** High contrast, readable on mobile at thumb size
- **CTAs:** Clear next steps (link in bio, DM, etc.)
- **Timing:** Post when your audience is most active
- **Engagement:** Reply to comments within first hour

## 💬 Customization Help

All templates include:
- **Editable HTML** - Modify text directly in source
- **CSS Variables** - Easy color changes
- **Flexible Layouts** - Adapts to content length
- **Mobile-Friendly** - Looks good on all devices

### Common Customizations:

**Change gradient colors:**
```css
background: linear-gradient(135deg, #COLOR1 0%, #COLOR2 100%);
```

**Update text:**
```html
<div class="main-text">YOUR TEXT HERE</div>
```

**Adjust font sizes:**
```css
.main-text { font-size: 72px; }
```
